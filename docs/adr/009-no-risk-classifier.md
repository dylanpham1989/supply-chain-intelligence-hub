# ADR 009: No shipment risk classifier

Date: 2026-09-24
Status: Accepted

## Context

The original scope included a model that labels shipments on time, at risk or
delayed. The only data available is generated by a seeding script.

## Decision

Not built. The phase was dropped rather than shipped on synthetic labels.

## Alternatives considered

| Option | Why not |
|---|---|
| Train on the generated data and report metrics | The metrics would describe the generator, not the world. The first question about where the labels came from ends the conversation badly |
| Train and present it as a pipeline demonstration only | Defensible, but it spends a day to prove what the ingestion and retrieval work already proves: that the plumbing runs |
| Buy or find a public logistics dataset | The realistic option, and a real project. It is not this project |

## Consequences

Positive: nothing in the repository claims an accuracy number that cannot be
defended. The effort went into observability and deployment, which are proven
by running rather than by a number.

Negative: the project demonstrates retrieval and generation but no supervised
learning. If that specific skill is what someone wants to see, it is not here.

Revisit when: a real labelled dataset exists. The place it would attach is a
worker task writing to the existing `alerts` table, with a model card covering
data source, label definition, class balance and calibration.
